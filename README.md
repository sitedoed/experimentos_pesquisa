# Framework G(t) - Modelagem Explicável de Fenômenos Emergentes

## Descrição
Este projeto implementa um framework para modelagem e análise de fenômenos emergentes em sistemas de recomendação, combinando:
- Teoria de Sistemas Complexos
- Knowledge Graphs
- Explicabilidade Sistêmica

## Resultados Demonstrados
- **Bolhas de filtro**: Redução de 85% na diversidade informacional
- **Efeito superestrela**: Concentração de 95% nos top-5 itens
- **Validação empírica**: Assinaturas estruturais observáveis

## Requisitos do Sistema
- **Sistema Operacional**: Linux (Ubuntu 18.04+), macOS, ou Windows (WSL2)
- **Python**: Versão 3.8 ou superior
- **Memória RAM**: 4GB mínimo (8GB recomendado)
- **Espaço em disco**: ~500MB para dependências e resultados

### Instalação
# Criar ambiente virtual
python3 -m venv pesquisa

# Ativar ambiente
source pesquisa/bin/activate  # Linux/Mac
# ou
pesquisa\Scripts\activate     # Windows

# Instalar dependências
pip install -r requirements.txt
